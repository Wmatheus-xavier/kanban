Descrição detalhada

Controladora de servico de cartao de atividade.

Implementa IServicosCartaoDeAtividade com todas as regras de negocio:

criar: quadro e desenvolvedor devem existir; estado inicial obrigatorio "A FAZER".

atualizar: altera apenas nome, descricao, prioridade e tamanho; preserva estado, entrada, inicio, termino e relacoes.

mover (A FAZER -> FAZENDO):

  • Falha se WIP atual do quadro >= limite do quadro.
  • Falha se momento < entrada do cartao.
  • Grava inicio = momento.

mover (FAZENDO -> FEITO):

  • Falha se momento < inicio do cartao.
  • Grava termino = momento.

Metricas (em MINUTOS, calculadas com timestampParaMinutos()):

  • tempo de ciclo = termino - inicio (apenas para cartoes FEITO)
  • lead time = termino - entrada (apenas para cartoes FEITO)
  • WIP = numero de cartoes do quadro em FAZENDO

◆ mover()

bool CntrServicosCartaoDeAtividade::mover ( const Identificador &  cartao,
const Estado &  destino,
const Timestamp &  momento 
)
overridevirtual

Move um cartao para o proximo estado, gravando o timestamp correto.

Transicoes validas:

  • A FAZER -> FAZENDO: grava inicio=momento. Falha se WIP do quadro >= limite ou momento < entrada.
  • FAZENDO -> FEITO: grava termino=momento. Falha se momento < inicio.
Parâmetros
cartaoIdentificador do cartao
destinoEstado destino (FAZENDO ou FEITO)
momentoTimestamp do instante da movimentacao
Valores Retornados
trueMovido; timestamp gravado
falseCartao inexistente, transicao invalida, WIP excedido ou momento anterior ao ultimo timestamp do cartao
