Descrição detalhada

Controladora de interface de usuario para cartoes de atividade.

Exibe menus e le dados via cin/cout para as operacoes sobre cartoes. Criacao, atualizacao e exclusao sao restritas ao GESTOR. Leitura, listagem, movimentacao e metricas estao disponiveis para ambos os papeis.
