Descrição detalhada

Interface dos servicos de cartao de atividade.

Oferece CRUD, movimentacao entre colunas e metricas sobre cartoes.

virtual bool IServicosCartaoDeAtividade::mover ( const Identificador &  cartao,
const Estado &  destino,
const Timestamp &  momento 
)
pure virtual

Move um cartao para o proximo estado.

Transicoes validas: A FAZER -> FAZENDO e FAZENDO -> FEITO. Ao ir para FAZENDO grava inicio=momento; ao ir para FEITO grava termino=momento.

Parâmetros
cartaoIdentificador do cartao a mover
destinoEstado de destino
momentoTimestamp do momento da movimentacao
Valores Retornados
trueCartao movido
falseCartao nao encontrado, transicao invalida, WIP excedido ou momento invalido

Implementado por CntrServicosCartaoDeAtividade.
